IoT Traffic Light開發(一)

前言

對於行控中心架構下的交通號誌模擬，我們選用Witty Cloud硬體來模擬，它是基於ESP8266開發的物聯網裝置，主要是ESP8266已內建WiFi模組，以及硬體上也已裝設了三色LED，正好拿來模擬交通號誌而不必額外架設硬體。

開發上我們預計分三階段進行，第一是Witty Could的WiFi及LED設定，第二是MQTT Heartbeat及Witty Cloud Timer設定，最後則是MQTT的IoT裝置註冊及燈號狀態更新與行控中心搭配。

認識機智雲(Witty Cloud)

機智雲有內建三色(RGB)LED燈，分別是紅色(GPIO15)、綠色(GPIO12)及藍色(GPIO13)。想要控制機制雲(其實是ESP8266)的GPIO，必須導入Pin模組，方法如下: 

from machine import Pin

r_led = Pin(15, Pin.OUT)
g_led = Pin(12, Pin.OUT)
b_led = Pin(13, Pin.OUT)

r_led.on()

機智雲的WiFi設定

要使用ESP8266的WiFi，必須套用network模組，又ESP8266可以規劃成WiFi的Station及AP，因為我們是一個裝置，因此只須規劃成WiFi Station。 

import network
import json

def wifi_connect(led):
  wifi = network.WLAN(network.STA_IF)
  wifi.active(True)
  with open('config.json', 'rt') as f:
      cfg = json.load(f)
      wifi.connect(cfg['ssid'], cfg['password'])
  while wifi.isconnected() == False:
      pass

  led.value(0)
  print(wifi.ifconfig())
  return wifi

模擬交通號誌

交通號誌主要是紅 → 綠 → 黃 → 紅的循環顯示，因此只需要使用while迴圈來控制燈號即可。但是機智雲並沒有黃燈，因此要變換黃燈時，必須同時點亮紅燈與綠燈。程式碼設計就會如同下方程式碼。 

from machine import Pin 
import utime 

OFFLINE = 0
RED = 1
YELLOW = 2
GREEN = 3

led_cfg = {
  "red": 10,
  "yellow": 5,
  "green": 15,
  "blink": 0
}

led_status = OFFLINE
r_led = Pin(15, Pin.OUT)
g_led = Pin(12, Pin.OUT)
b_led = Pin(13, Pin.OUT)

leds = [r_led, g_led, b_led]

def led_off():
  for led in leds:
      led.off()

def led_change(led: int):
  print(f"led_change()  ==> led = {led}")
  led_off()
  if led == RED:
      r_led.on()
  elif led == YELLOW:
      r_led.value(1)
      g_led.value(1)
  elif led == GREEN:
      g_led.value(1)
  led_status = led

def traffic_test(leds, cfg):
  r = cfg['red']
  y = cfg['yellow']
  g = cfg['green']

  while True:
      led_change(RED)
      utime.sleep(r)
      led_change(GREEN)
      utime.sleep(g)
      led_change(YELLOW)
      utime.sleep(y)

def start_light():
  led_off()
  led_status = RED
  traffic_test(leds, led_cfg)

兩個容易踩到的細節

第一，led_change() 內若要更新模組層級的 led_status，需加上 global led_status，否則只會產生區域變數。第二，start_light() 原本先設 led_status = RED 卻沒實際點燈，建議直接呼叫 led_change(RED) 讓狀態與硬體一致。
